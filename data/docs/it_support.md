# IT support service

Owner: Corporate Operations
Effective: January 1, 2026. Company: Atlas Grove (fictional).

Contact IT Support through ServiceDesk for equipment, account, network, and software problems. Standard staffed hours are Monday through Friday, 8:00 a.m. to 6:00 p.m. in each office time zone, excluding local public holidays. Include the device asset tag, affected service, start time, and a screenshot with sensitive information removed. Never include passwords in a ticket.

Priority 1 incidents affect an entire office or a critical production service and have a 15-minute acknowledgement target. Priority 2 issues blocking one employee have a 2-business-hour target. Priority 3 requests have a 1-working-day target. Response targets measure acknowledgement rather than guaranteed resolution. Security incidents must also be reported through the Security Hotline, even if an IT ticket exists.

Use the Software Request workflow for new applications. The system owner and Security review licensing and data handling before installation. Standard approved applications are usually provisioned within 2 working days. Employees may reopen a resolved ticket within 5 working days if the same issue persists. Escalate overdue urgent requests to the duty support lead using the original ticket number. Unapproved remote support tools must not be installed on managed devices.

This fictional policy applies to Atlas Grove employees unless a local employment agreement provides a different entitlement. The policy owner reviews it each January. For an exception, submit a Policy Exception request in the People Portal with a business reason, proposed end date, and manager endorsement. Approval must be recorded before the exception begins; informal chat messages do not change policy. Questions go to the named service team through the internal help portal.
